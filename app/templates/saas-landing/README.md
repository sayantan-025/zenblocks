# SaaS Landing — Pro Template

A premium, high-performance SaaS landing page template built with ZenBlocks.

## Features
- 10+ Essential Landing Page Sections
- Physics-Driven UI Components (Orb Field, Logo Loop, etc.)
- Fully Responsive & Dark Mode Ready
- Built with Next.js 15, Tailwind CSS, and Framer Motion
- Clean, Standalone Architecture

## Getting Started

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Run Development Server:**
   ```bash
   npm run dev
   ```

3. **Build for Production:**
   ```bash
   npm run build
   ```

## Folder Structure
- `components/`: UI components and sections.
  - `zenblocks/`: Core ZenBlocks primitives.
- `data/`: Content and data files for the landing page.
- `hooks/`: Custom React hooks.
- `lib/`: Utility functions and configuration.
- `types/`: TypeScript type definitions.
